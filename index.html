Begin with a name

Enter any ticker above. The model will return a composite score across ten dimensions, place it in a Graham-quartile, sketch bear/base/bull paths over 3M, 1Y, 5Y and 10Y, and read the case through eight analytical lenses.

The Concentric Value Model integrates Benjamin Graham's defensive criteria (1973) with literature on financial engineering, technology adoption, governance, ownership concentration, and organisational practices. Layer weights are proposed based on qualitative research and the Concentric Value Model — the tool invites researchers to empirically test them. Per-company composite scores reflect a single firm's alignment with the framework's ten dimensions at the time of measurement; they are not return forecasts, peer rankings, or relative-value statements. A higher score does not imply a higher expected return.

The model uses sector-baseline fundamentals (median P/E, P/B, EPS growth, etc.) drawn from publicly available reference ranges for instant analysis on any ticker. For the ~200 names in the curated reference universe, fundamentals are refreshed quarterly via an automated pipeline drawing on Yahoo Finance, World Bank macroeconomic data, and Finnhub ESG scores; the resulting scores may be up to 90 days old between refreshes. For sharper reads on any name at any time, click Look up on Yahoo Finance, copy the current price and key ratios from there, and paste them in.
