# Concentric_Value_Model

A modernized extension of Benjamin Graham’s value criteria across ten dimensions and six concentric layers.

**Live tool:** <https://felixdlanger.github.io/Concentric_Value_Model/>

## What this is

An analytical framework demonstrator. Enter any ticker and the model returns a composite score across ten dimensions (financial metrics, financial engineering, technology adoption, strategic transformation, management stake, ownership structure, culture, progressive practices, macro environment, market dynamics), placed within four quartiles.

## How to use

1. Type a ticker or company name (e.g. “Apple” or “AAPL”)
1. Run Analysis to see sector-baseline scoring
1. Paste Yahoo Finance summary to sharpen 2–4 dimensions
1. Use the per-dimension Sharpen affordances to populate the remaining six

## Methodology

Layer weights are derived from qualitative research on the Concentric Value Model. Full methodology is detailed in the underlying DBA paper by Felix Langer.
